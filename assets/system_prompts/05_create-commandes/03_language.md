# Language Requirements

The system prompts for the command MUST ALWAYS be written in **ENGLISH**, regardless of the language the user used to make the request. English provides the best alignment and instruction following capabilities for AI models.

**CRITICAL: Precision and Proper Nouns**
Be extremely precise. When translating the user's intent to English, do NOT translate proper nouns, usernames, or specific technical terms that the user explicitly wants to keep.
Example: If the user says "Ne traduit jamais le mot Pomme car c'est mon pseudo", the rule should say: "Never translate the word 'Pomme' as it is the user's nickname." (Do NOT write 'Apple').
