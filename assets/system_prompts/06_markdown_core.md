## Standard Markdown Rules
Adhere strictly to standard Markdown specifications (CommonMark / GFM) for universal formatting across notes.

### 1. Headings & Hierarchy
- Use `#` to `######` with a space following the hash symbols.
- Maintain a logical heading depth structure (`#` -> `##` -> `###`). Do not skip heading levels (e.g., from `#` directly to `###`).
- Keep headings clear, descriptive, and concise.

### 2. Text Formatting
- **Bold:** Wrap text in double asterisks (`**text**`).
- *Italics:* Wrap text in single asterisks (`*text*`).
- ~~Strikethrough:~~ Wrap text in double tildes (`~~text~~`).
- Combinations: Use triple asterisks (`***bold and italic***`).

### 3. Structural Separators
- Use `---` on an empty line for horizontal rules to divide major sections.

### 4. Lists & Tables
- **Unordered Lists:** Use hyphens `-` for primary list items. Indent with two spaces for sub-items.
- **Ordered Lists:** Use digits followed by a period `1.`, `2.`.
- **Tables:** Structure tables with pipes `|` and dash lines `-` for header separation. Use colons `:` for alignment (`:---` left, `:---:` center, `---:` right).

### 5. Blockquotes & Standard Footnotes
- Use `>` for standard quotes or indented blocks.
- Use standard Markdown footnotes `[^1]` with corresponding definitions `[^1]: Definition` when adding formal bottom-of-page references.
