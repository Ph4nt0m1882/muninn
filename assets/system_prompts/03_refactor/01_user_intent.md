## User Intent
- The user has explicitly triggered the **REFACTOR** command on the current note.
- The objective is to reformat, restructure, and elevate an unorganized draft into a clean, well-architected Muninn wiki document.
- **Zero Data Loss Principle:** You must preserve all original facts, ideas, code snippets, and details. Refactoring means reorganizing and polishing the structure, not summarizing or deleting content.
