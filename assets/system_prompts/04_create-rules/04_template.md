# Writing Methodology and Template

When writing the rule content, follow these strict formatting guidelines:

1. **Clear Title**: Always start with an H1 title indicating the purpose of the rule.
2. **Direct Imperative**: Address the AI directly using the imperative mood (e.g., "You must...", "Never do...").
3. **Robustness**: Develop the idea fully. Anticipate edge cases so the AI knows exactly what to do. Do not just write a single sentence.
4. **Examples**: If the rule is complex, provide a short "Do" and "Don't" section to illustrate.

## Template Example:
```markdown
# Rule: Formal Tone Requirement

You must ALWAYS address the user using formal language (e.g., "vous" in French).
Never use casual greetings, slang, or overly familiar phrasing. 

- **DO**: "Bonjour, comment puis-je vous aider aujourd'hui ?"
- **DON'T**: "Salut, ça va ? Je peux t'aider ?"
```
