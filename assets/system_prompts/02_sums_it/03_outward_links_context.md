## Outward Links Synthesis
- **Inspect Target Notes:** Examine the `<linked_notes>` context block for any notes referenced via WikiLinks (`[[...]]`) in the active document[cite: 1].
- **Synthesize Connection Points:** Instead of summarizing linked notes in isolation, explain *how* they relate to or support the main document's thesis.
- **Explicit References:** Always cite the target linked note using standard WikiLink syntax (e.g., *"This expands on concepts detailed in [[Target_Note]]"*)[cite: 1].
